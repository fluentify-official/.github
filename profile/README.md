## 📖 About Fluentify

**Fluentify** is an AI-powered English learning platform designed to help Vietnamese learners develop their English proficiency through structured learning paths, personalized educational content, interactive exercises, and intelligent AI assistance.

Fluentify addresses common challenges faced by Vietnamese English learners, including:

- Difficulty understanding English grammar and sentence structures.
- Limited vocabulary and difficulties remembering new words.
- Challenges with English pronunciation and listening comprehension.
- Lack of confidence when communicating in English.
- Difficulty finding suitable learning materials for individual proficiency levels.
- Lack of a consistent and personalized learning roadmap.

Rather than providing a one-size-fits-all learning experience, Fluentify aims to create an adaptive learning environment that considers each learner's current proficiency, learning goals, strengths, and weaknesses.

The platform combines Vietnamese-supported explanations with practical English exercises to help learners gradually transition from understanding English to using it confidently in real-life situations.

### 🎯 Our Vision

To become a comprehensive, AI-powered English learning platform that empowers Vietnamese learners to master English through personalized, accessible, and effective learning experiences.

### 🚀 Our Mission

- Make English learning more accessible to Vietnamese learners.
- Provide structured learning paths based on individual proficiency levels.
- Bridge the gap between Vietnamese explanations and practical English usage.
- Help learners develop all four essential English skills.
- Apply artificial intelligence to personalize and enhance learning experiences.
- Build a sustainable learning environment that encourages consistency and continuous improvement.
- Help Vietnamese learners become more confident in using English in academic, professional, and everyday contexts.

## 🎓 Target Learners

Fluentify is designed for Vietnamese learners with different English proficiency levels, backgrounds, and learning objectives.

### 👥 Learner Groups

| Target Group | Learning Needs |
|---|---|
| Beginners | Build foundational vocabulary, grammar, and basic communication skills. |
| Elementary Learners | Develop everyday communication and understand common sentence structures. |
| Intermediate Learners | Improve fluency, comprehension, and practical English usage. |
| Upper-Intermediate Learners | Develop more advanced communication and academic language skills. |
| Advanced Learners | Refine language accuracy, fluency, and professional communication. |

### 📊 English Proficiency Levels

Fluentify uses the Common European Framework of Reference for Languages (CEFR) as a reference framework for organizing learning levels.

| Level | Description | Learning Focus |
|---|---|---|
| A1 | Beginner | Basic vocabulary, simple sentences, and everyday expressions. |
| A2 | Elementary | Common conversations and familiar daily situations. |
| B1 | Intermediate | Independent communication and practical language usage. |
| B2 | Upper-Intermediate | More complex communication and comprehension. |
| C1 | Advanced | Fluent communication and advanced language structures. |
| C2 | Proficient | Near-native comprehension and precise language usage. |

*CEFR serves as a reference for proficiency classification and learning progression. Course structures, assessments, and learning outcomes will be developed to align with the framework.*

## 📚 Learning Methodology

Fluentify follows a structured and progressive learning approach that combines foundational knowledge, practical exercises, continuous assessment, and personalized feedback.

### 1. Core English Skills

The platform focuses on developing the four essential English language skills.

| Skill | Description | Learning Activities |
|---|---|---|
| 📖 Reading | Improve reading comprehension and vocabulary recognition. | Reading passages, comprehension questions, and vocabulary extraction. |
| 🎧 Listening | Develop listening comprehension and recognize spoken English. | Audio exercises, conversations, and listening assessments. |
| 🗣️ Speaking | Improve pronunciation, fluency, and communication confidence. | AI conversations, speaking exercises, and pronunciation practice. |
| ✍️ Writing | Develop sentence construction, grammar accuracy, and writing skills. | Sentence building, writing exercises, and AI feedback. |

### 2. Language Foundations

In addition to the four core skills, Fluentify provides dedicated learning modules for essential language knowledge.

- 📚 **Vocabulary:** Learn words through topics, contexts, examples, and spaced repetition.
- 📝 **Grammar:** Understand English grammar through structured lessons and Vietnamese explanations.
- 🔤 **Pronunciation:** Learn pronunciation, phonetics, and sound recognition.
- 💬 **Expressions:** Practice common phrases, collocations, and natural English expressions.

### 3. Personalized Learning Paths

Each learner follows a learning path based on their proficiency level, learning objectives, and assessment results.

The learning process is designed around:

1. Initial proficiency assessment.
2. Learning level identification.
3. Personalized course recommendations.
4. Structured lessons and exercises.
5. Continuous progress evaluation.
6. Adaptive learning recommendations.

The objective is to help learners focus on the areas where they need improvement instead of following an identical learning path.

## 🤖 AI-Powered Learning

Artificial Intelligence is a core component of Fluentify, supporting personalized learning, interactive practice, and intelligent feedback.

### AI Learning Capabilities

| Feature | Description |
|---|---|
| 💬 AI English Tutor | Explain English concepts and answer learning-related questions. |
| 🧠 Vietnamese Explanations | Explain vocabulary, grammar, and sentence structures in Vietnamese. |
| 🗣️ AI Conversation | Simulate interactive English conversations based on different situations. |
| 🎙️ Speech Recognition | Convert spoken English into text for learning activities. |
| 🔊 Text-to-Speech | Generate spoken English for listening and pronunciation practice. |
| 📢 Pronunciation Assessment | Analyze pronunciation and provide improvement feedback. |
| ✍️ AI Writing Assistant | Evaluate writing and suggest grammar and vocabulary improvements. |
| 🎯 Adaptive Learning | Recommend learning content based on learner performance. |
| 📝 Exercise Generation | Generate supplementary exercises for different learning objectives. |
| 📊 Learning Analytics | Analyze learning activities and identify areas for improvement. |

### 🇻🇳 Designed for Vietnamese Learners

Fluentify aims to address language-learning difficulties commonly experienced by Vietnamese learners.

Key considerations include:

- Vietnamese explanations for complex English grammar concepts.
- Comparisons between Vietnamese and English sentence structures.
- Recognition of common grammar and vocabulary mistakes made by Vietnamese learners.
- Pronunciation practice focusing on English sounds that may be challenging for Vietnamese speakers.
- Practical examples based on familiar Vietnamese and international contexts.
- Gradual transition from Vietnamese-supported learning to English-based learning.

The goal is not to make learners permanently dependent on Vietnamese translations, but to use Vietnamese as a bridge toward independent English comprehension and communication.

## 🔒 Security & Privacy

Security and user privacy are important principles throughout the Fluentify ecosystem.

- Never commit API keys, passwords, or access tokens.
- Keep sensitive credentials in environment variables or secret management services.
- Use secure authentication and authorization mechanisms.
- Enforce role-based permissions for administrative operations.
- Validate and sanitize incoming requests.
- Apply appropriate rate limiting to public APIs and AI endpoints.
- Protect personal learning data and enforce access controls.
- Maintain audit logs for sensitive operations.
- Validate uploaded educational content and datasets.
- Follow responsible data retention and deletion practices.
- Avoid exposing sensitive information in application logs.
- Protect AI-related requests and user-generated content.
